# 测试策略

> 全量交付阶段的测试基线：分层、覆盖目标、必测场景、测试数据与 CI 门禁。
> 原则：关键路径必须有自动化测试；缺陷修复先写复现测试（规范 §6）。

## 1. 测试分层

| 层级 | 范围 | 工具 | 目标 |
| --- | --- | --- | --- |
| 单元测试 | 领域逻辑、权限判定、状态机、工具类、Provider 解析 | JUnit 5 + Mockito（后端）、Vitest（前端，按需） | 快、无外部依赖，覆盖核心分支 |
| 接口/集成测试 | Controller + Service + Mapper（测试库）、认证/权限、分页 | Spring Boot Test（@Transactional 回滚） | 覆盖 API 契约与权限边界 |
| 端到端（E2E） | 注册→登录→创建频道→发帖→评论→互动→管理→私信→AI | Playwright / 无头 Chrome（`tools/e2e`） | 核心用户旅程 |
| 契约测试 | 前后端接口字段（响应模型） | OpenAPI 校验 / 适配层类型 | 防止 DTO 漂移（M1 已出现一次字段不一致） |
| 安全测试 | 越权（IDOR）、上传、注入、限流 | 手工用例 + 自动化脚本 | 权限边界不可绕过 |
| 性能测试 | 核心读/写接口、AI 流式 | 压测脚本（k6/wrk 视环境） | 满足 docs/03 §9 预算 |

覆盖率目标：核心业务域 ≥ 85%，整体 ≥ 70%（新增代码不低于基线）。

## 2. 必测场景（全量）

### 认证与权限
- 注册重名/弱密码/超长；登录失败限流；refresh 轮换/撤销/过期；登出。
- 游客只读：可读公开频道/帖子/评论/搜索；写操作 401；私密频道 404。
- 频道可见性：`MEMBERS_ONLY` 非成员不可见；`PUBLIC_VISIBLE` 私密频道可浏览不可发帖。
- 权限矩阵：频道主/超管/板块管理员/普通成员 × 操作（发帖、置顶、精华、删除、成员管理、禁言、角色管理、邀请、日志、数据、助手设置、解散）。
- 越权：修改他人频道/帖子/评论/私信 URL；非参与者读取私信；越权审批加入申请。

### 频道与内容
- 创建频道初始化（频道号、默认板块、四个系统身份组、频道主成员）。
- 板块 CRUD、板块管理员范围、板块删除后帖子处理。
- 发帖（快捷/长文/媒体/板块归属/禁言）、编辑/删除、置顶/取消、精华/取消、批量操作。
- 评论（顶级/回复/楼中楼、排序、点赞、作者名牌、媒体）、删除。
- 浏览量/点赞/分享计数；分享给好友/复制链接。
- 管理员日志完整性（谁/何时/对什么/结果）。

### 社交与实时
- 好友申请/同意/拒绝/删除/拉黑；防重复申请；被拉黑不可私信。
- 私信会话/消息/未读/已读/分页；非参与者 403/404；非法内容/超长消息。
- STOMP 连接鉴权（无 token/过期 token 拒绝）、`/user/queue/dm` 推送、断线重连补拉。
- 通知：互动与系统消息、未读计数、全部已读、跳转 payload。

### 发现与搜索
- 热门排序（浏览/点赞/评论/时间衰减）；频道推荐理由与加入。
- 搜索：关键词/历史（单条/清空）、联想（已加入频道前缀 + 热词）、频道/帖子结果排序筛选、频道内搜索、公开范围（私密内容不索引）。
- LIKE 通配符转义、超长关键词、空关键词。

### AI（频道问问 / 频道助手）
- 模型配置 CRUD、连通性测试、未配置模型时的错误提示。
- 会话/消息持久化；流式输出与中断；重新生成；编辑重发（截断后续消息）；图片（vision 模型缺失时降级/提示）；来源引用。
- 检索上下文：仅公开帖子/本频道内容；token 上限。
- 频道助手：persona 配置、任务开关/频率上限、执行日志、失败重试；自动发帖/评论/点赞的权限与内容落库。
- Mock Provider 测试（`tools/mock-openai`）+ 真实 LMStudio 联调（如可用）。

### 平台后台
- 平台管理员鉴权（非管理员 403）。
- AI 配置、举报处置（状态机/通知）、用户/频道禁用与恢复、平台数据概览。

## 3. 测试数据与环境

- 本地库：`my_social_channel_test`；集成测试 `@Transactional` 回滚；测试间不共享状态。
- E2E：每次运行创建独立用户/频道（带时间戳前缀），结束后不清理（dev 库）或脚本清理。
- 夹具：种子数据脚本（可选）生成公开/私密频道、角色成员矩阵。
- Mock：外部 AI 用 `tools/mock-openai`；邮件/短信等外部服务未接入。

## 4. CI 门禁（目标）

```
install → format → lint → typecheck → unit test → build → integration test → security scan → e2e(可选)
```

- 后端：`mvn -B test` 必过；`mvn -B -DskipTests package` 必过。
- 前端：`pnpm build`（含 vue-tsc）必过；后续补 ESLint。
- 合并前检查清单见 docs/00 附录 B。

## 5. E2E 场景清单（tools/e2e）

1. 注册 → 登录 → 创建公开频道 → 发帖 → 评论 → 点赞 → 搜索到帖子。
2. 游客访问公开频道/帖子 → 尝试发帖被引导登录。
3. 创建私密频道 → 生成邀请链接 → 另一账号审批加入 → 可见性验证。
4. 管理员：置顶/精华/删除/禁言/全员禁言/成员管理/查看管理日志与数据中心。
5. 好友申请 → 同意 → 私信发文本/图片/帖子分享（WebSocket 实时到达）。
6. 频道问问：提问 → 流式回答 → 重新生成 → 编辑重发（mock AI）。
7. 频道助手：配置 persona/任务 → 手动触发总结 → 帖子落库。
8. 平台后台：AI 配置连通性测试、举报处置、用户禁用。

## 6. 缺陷与质量

- 缺陷分级与流程见 docs/00 §16；修复必须附回归测试。
- flaky 测试零容忍：隔离并登记，不允许重试掩盖。
- 每个工作包完成即跑对应测试并记录在 docs/10 §6。
