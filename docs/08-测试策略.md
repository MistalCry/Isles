# 测试策略

> 全量交付阶段的测试基线：分层、覆盖目标、必测场景、测试数据与 CI 门禁。
> 原则：关键路径必须有自动化测试；缺陷修复先写复现测试（规范 §6）。

## 1. 测试分层

| 层级 | 范围 | 工具 | 目标 |
| --- | --- | --- | --- |
| 单元测试 | 领域逻辑、权限判定、状态机、工具类、Provider 解析 | JUnit 5 + Mockito（后端）、Vitest（前端） | 快、无外部依赖，覆盖核心分支 |
| 组件测试 | 关键展示组件的渲染与交互（卡片/评论/媒体/提及） | Vitest + @vue/test-utils + happy-dom | 不依赖真实浏览器与后端，锁住渲染回归 |
| 文案守卫 | i18n key 完整性、硬编码文案、语法字符转义 | Vitest（扫描源码原文） | 迁移后不回退，文案问题在 CI 阶段暴露 |
| 接口/集成测试 | Controller + Service + Mapper（测试库）、认证/权限、分页 | Spring Boot Test（@Transactional 回滚） | 覆盖 API 契约与权限边界 |
| 端到端（E2E） | 注册→登录→创建频道→发帖→评论→互动→管理→私信→AI | Playwright / 无头 Chrome（`tools/e2e`） | 核心用户旅程 |
| 契约测试 | 前后端接口字段（响应模型） | OpenAPI 校验 / 适配层类型 | 防止 DTO 漂移（M1 已出现一次字段不一致） |
| 安全测试 | 越权（IDOR）、上传、注入、限流 | 手工用例 + 自动化脚本 | 权限边界不可绕过 |
| 性能测试 | 核心读/写接口、AI 流式 | 压测脚本（k6/wrk 视环境） | 满足 docs/03 §9 预算 |

覆盖率目标：核心业务域 ≥ 85%，整体 ≥ 70%（新增代码不低于基线）。

## 2. 必测场景（全量）

### 认证与权限
- 注册重名/弱密码/超长；登录失败限流；refresh 轮换/撤销/过期；登出。
- 游客只读：可读公开频道/帖子/评论/搜索；写操作 401；私密频道 404。
- 频道可见性：`MEMBERS_ONLY` 非成员不可见；`PUBLIC_VISIBLE` 私密频道可浏览不可发帖。
- 权限矩阵：频道主/超管/板块管理员/普通成员 × 操作（发帖、置顶、精华、删除、成员管理、禁言、角色管理、邀请、日志、数据、助手设置、解散）。
- 越权：修改他人频道/帖子/评论/私信 URL；非参与者读取私信；越权审批加入申请。

### 频道与内容
- 创建频道初始化（频道号、默认板块、四个系统身份组、频道主成员）。
- 板块 CRUD、板块管理员范围、板块删除后帖子处理。
- 发帖（快捷/长文/媒体/板块归属/禁言）、编辑/删除、置顶/取消、精华/取消、批量操作。
- 评论（顶级/回复/楼中楼、排序、点赞、作者名牌、媒体）、删除。
- 浏览量/点赞/分享计数；分享给好友/复制链接。
- 管理员日志完整性（谁/何时/对什么/结果）。

### 社交与实时
- 好友申请/同意/拒绝/删除/拉黑；防重复申请；被拉黑不可私信。
- 私信会话/消息/未读/已读/分页；非参与者 403/404；非法内容/超长消息。
- STOMP 连接鉴权（无 token/过期 token 拒绝）、`/user/queue/dm` 推送、断线重连补拉。
- 通知：互动与系统消息、未读计数、全部已读、跳转 payload。

### 发现与搜索
- 热门排序（浏览/点赞/评论/时间衰减）；频道推荐理由与加入。
- 搜索：关键词/历史（单条/清空）、联想（已加入频道前缀 + 热词）、频道/帖子结果排序筛选、频道内搜索、公开范围（私密内容不索引）。
- LIKE 通配符转义、超长关键词、空关键词。

### AI（频道问问 / 频道助手）
- 模型配置 CRUD、连通性测试、未配置模型时的错误提示。
- 会话/消息持久化；流式输出与中断；重新生成；编辑重发（截断后续消息）；图片（vision 模型缺失时降级/提示）；来源引用。
- 检索上下文：仅公开帖子/本频道内容；token 上限。
- 频道助手：persona 配置、任务开关/频率上限、执行日志、失败重试；自动发帖/评论/点赞的权限与内容落库。
- Mock Provider 测试（`tools/mock-openai`）+ 真实 LMStudio 联调（如可用）。

### 举报与配置（用户实测回归）
- 举报原因：界面只提交代码（`SPAM|ABUSE|PORN|ILLEGAL|OTHER`），中英文界面都必须能举报帖子与评论；
  把界面文案当 reason 提交必须被 400 拒绝（历史 bug：i18n 改造后前端发了中文文案）。
- 配置即时生效：改 `site.name` 后立刻 `GET /platform/config` 必须返回新值，**60 秒内连续改两次都即时**；
  恢复默认同样即时；响应必须 `Cache-Control: no-store` 且不带 ETag。

### 内容链路（用户实测回归）
- 浏览量：作者自己刷新不计；同一账号 30 分钟内重复访问只计一次；换账号（换会话）再计一次。
- 敏感词三模式（全局 `content.sensitiveWord.mode`）：REVIEW 原文入库只记命中；MASK 入库为 `***`；BLOCK 返回 422 `SENSITIVE_WORD_BLOCKED`。
- 搜索缩略图：搜索命中的帖子带 `coverUrl`（显式封面）与 `media`（sort 最小的首图）。

### 媒体上传
- `heic` / `avif` / `mov` 上传成功且能回读；非法类型、声明类型与真实类型不符被 400 拒绝；
  ffmpeg 不可用时降级为「原图直出 / 无封面」，上传仍成功。

### AI 来源引用（用户实测回归）
- 工具模式：SSE 必须下发 `sources` 事件，且与落库消息的 `sources` 完全一致（刷新前后看到同一批）；
  0 命中时同样下发 `sources` 且为 `[]`（否则前端会一直显示 meta 里的关键词兜底来源）。
- 非工具模式：来源为关键词检索结果；前端在「没收到 sources 事件」时才回落 `meta.sources`。
- 前端：`sources` 事件整体替换 meta 兜底来源，不做追加。

### 帖子卡片展示（用户实测回归）
- 有封面：媒体区整体不渲染（封面独占）；无封面：最多 3 张，第 3 张盖「+N」且 N=剩余张数；不足 3 张不出「+N」。
- 有标题：正文摘要压到 2 行并按 120 字截断；无标题：3 行、220 字。
- 最高赞评论：有 `topComment` 渲染作者+60 字摘要+「查看全部」；无评论整块不渲染。

### 交互细节（用户实测回归）
- 上传：进度回调要真的透到按钮（`上传中 N%`），失败可重试；超时按文件大小估算（0.5MB/s，下限 120 秒）。
- 视频懒播放：进入视口 ≥50% 才 play，离开或未达阈值立即 pause；无 IntersectionObserver 环境保持暂停。
- 快捷评论弹窗：非频道成员（`canComment=false`）输入区换成「加入频道」提示，成员正常渲染输入区。

### 频道应用 / 语音房 / 活动（V10）
- 应用：CRUD、批量排序（sortOrder 0 起）、游客可读、默认不返回禁用项、无 `channel.settings` 不可写。
- 语音房：开房 → 两人进房 → 并发抢同一麦位（唯一键兜底，只有一个成功、另一个 409）→ 静音 → 下麦 → 关房；
  STOMP 信令 `/app/voice/{id}/signal` → `/topic/voice/{id}/signal` 透传（from=发送者，SDP 原样不解析）。
- 信令安全边界：非频道成员订阅/发送都返回 ERROR 帧 `code=NOT_IN_ROOM`（否则可白听 SDP/ICE）；
  关房后订阅/发送返回 `code=ROOM_CLOSED`（旧连接不能继续占用信令通道）。
- 级联：频道解散（软删除，FK CASCADE 不触发）后 `channel_apps` / `voice_rooms` / `voice_room_seats` /
  `channel_activities` 不留孤儿行——直接查库校验，接口对已解散频道一律 404 看不出问题。
- 活动：创建 → 发布 → 报名（幂等）→ 取消 → 人数上限 422 → 开始前 30 分钟提醒只发一次（`reminder_sent_at` 抢占）。

### AI 用户代理（V13 / docs/12）
- 创建代理：账号 `is_agent=1`、用户名自动生成 `agent_` 前缀、人设 `ACTIVE`；列表可见。
- run-now：产出帖子/评论，`posts.is_ai_generated=1` / `comments.is_ai_generated=1`，作者是代理账号。
- 闸门：日发帖上限（`postsPerDay`）→ `GUARDED` 且理由说明上限；同话题 7 天去重 → `GUARDED` 且理由说明重复
  （注意发帖间隔 ≥2 小时排在去重之前，验证去重需先把上一次运行时间回拨）。
- 暂停：`PAUSED` 后 run-now 必须 `SKIPPED`（或 4xx），调度 `selectActive()` 不再挑选。
- 总开关：`agent.enabled=false` → run-now `SKIPPED` 且不写运行日志；tick 直接返回，全站停止。
- 降级：无可用模型 → 记 `SKIPPED`（不是 FAILED、不抛异常）。
- 可回放：`agent_runs` 含 `plan_json` / `tool_calls_json` / `output_type` / `output_id` / `tokens_in|out`。
- AI 标识字段（docs/12 §6，合规硬性）：帖子列表/详情带 `isAiGenerated` + `authorIsAgent`，评论列表带同名字段，
  作者公开资料与 `GET /auth/me` 带 `isAgent`；**代理内容为 true、真人内容为 false 两侧都要验**
  （只测 true 挡不住回归；注意当前用户接口是 `/auth/me`，`/users/me` 会被 `/users/{id}` 吞掉返回 404）。

### 用户中心与 AI 会话
- 我的帖子：`GET /users/me/posts` 只返回自己的、按时间倒序、`channelId` 过滤准确。
- 助手多会话：同频道可建多个 `CHANNEL_ASSISTANT` 会话，消息互不串；非成员创建 403。
- 视觉兼容：带图历史 + 无视觉模型 → 不报 400、回答正常，且服务端追加「已忽略 N 张图片」提示。

### 平台后台
- 平台管理员鉴权（非管理员 403）。
- 举报处置可达性：`GET /admin/reports?status=PENDING` 每条都必须可处置（`status=PENDING` 且带 `targetType`/`targetId`）；
  前端举报页默认筛选 `PENDING`，操作列 `fixed="right"`，处置按钮仅对 PENDING 启用。
- 配置中心：改站点名 → 公开配置 `GET /platform/config` 即时生效（不重启）→ 重置后回到默认值且 `platform_settings` 无残留行；
  非法值/越界值拒绝；非 `CONFIG_WRITE` 角色写入 403。
- 举报处置：`PENDING → ACCEPTED/REJECTED` 状态机、处置动作（下架/禁言/警告）落库、作者与举报人通知、
  下架后前台详情 404 与列表不可见、恢复后重新可见。
- 评论类举报 + `DELETE_CONTENT`：评论变 `HIDDEN`、举报变 `ACCEPTED`、举报人通知含被处置内容摘要
  （`comments` 表无 `updated_at`，SQL 写多列会 500）。
- 权限边界：`MODERATOR` 可处置举报、不可改配置/授权管理员；撤销授权后后台接口立即 403（角色缓存主动失效）。
- 公告状态机：草稿不公开 → 发布后公开 → 已发布直接删除 422 → 归档后可删除。
- 置顶：`latest` **完全排除**置顶帖，置顶只在 `GET /channels/{id}/posts/pinned` 出现；翻页不重复不漏。
- AI 配置、用户/频道禁用与恢复、平台数据概览。

## 3. 测试数据与环境

- 本地库：`my_social_channel_test`；集成测试 `@Transactional` 回滚；测试间不共享状态。
- E2E：每次运行创建独立用户/频道（带时间戳前缀），结束后不清理（dev 库）或脚本清理。
- 夹具：种子数据脚本（可选）生成公开/私密频道、角色成员矩阵。
- Mock：外部 AI 用 `tools/mock-openai`；邮件/短信等外部服务未接入。

## 4. CI 门禁（目标）

```
install → format → lint → typecheck → unit test → build → integration test → security scan → e2e(可选)
```

- 后端：`mvn -B test` 必过；`mvn -B -DskipTests package` 必过。
- 前端：`pnpm build`（含 vue-tsc）与 `pnpm lint` 必过；`pnpm format:check` 供格式化校验。
- 合并前检查清单见 docs/00 附录 B。

## 5. E2E 场景清单（tools/e2e）

1. 注册 → 登录 → 创建公开频道 → 发帖 → 评论 → 点赞 → 搜索到帖子。
2. 游客访问公开频道/帖子 → 尝试发帖被引导登录。
3. 创建私密频道 → 生成邀请链接 → 另一账号审批加入 → 可见性验证。
4. 管理员：置顶/精华/删除/禁言/全员禁言/成员管理/查看管理日志与数据中心。
5. 好友申请 → 同意 → 私信发文本/图片/帖子分享（WebSocket 实时到达）。
6. 频道问问：提问 → 流式回答 → 重新生成 → 编辑重发（mock AI）。
7. 频道助手：配置 persona/任务 → 手动触发总结 → 帖子落库。
8. 平台后台：AI 配置连通性测试、举报处置、用户禁用。
9. 平台后台护栏（`admin-console-audit.mjs`）：配置中心闭环、举报→下架→通知→恢复、MODERATOR 授权边界、公告状态机、置顶首屏。
10. 举报链路（`report-regression.mjs`）：中英文场景各举报帖子+评论、五种原因代码全覆盖、文案当代码被拒。
11. 上传格式（`media-regression.mjs`）：heic/avif/mov 上传+回读、非法类型拒绝、ffmpeg 缺失降级。
12. AI 工具调用（`ai-tools-regression.mjs`）：模型要工具→检索→二轮回答、来源来自真实命中、不支持 tools 时降级。
13. 助手模型（`assistant-model-regression.mjs`）：频道指定模型生效、任务日志记录模型 id、模型禁用后回落默认。
14. 来源引用（`ai-tools-regression.mjs`）：工具模式 sources 与落库一致、0 命中发空数组、非工具模式同样下发 sources。
15. 内容链路（`content-regression.mjs`）：浏览量去重（作者/30 分钟/换账号）、敏感词三模式、搜索缩略图。
16. 应用/语音房/活动（`apps-regression.mjs`）：应用 CRUD+排序、语音房抢座与 STOMP 信令、活动报名与提醒幂等。
17. 用户中心与 AI（`user-ai-regression.mjs`）：我的帖子过滤、助手多会话隔离、视觉模型降级。
18. AI 代理（`agent-regression.mjs`）：run-now 产出与 AI 标识、日上限、话题去重、暂停、总开关、无模型降级、运行日志回放；
    调度模式（`AGENT_TICK_MODE=1`）验证 tick 挑选 / 暂停后不再挑选 / 总开关全站停止。

## 6. 缺陷与质量

- 缺陷分级与流程见 docs/00 §16；修复必须附回归测试。

- 每个工作包完成即跑对应测试并记录在 docs/10 §6。
