## P0-1 富文本净化器吞掉站内相对地址（图片/视频"消失"的主因）

**文件**：`backend/src/main/java/com/isles/common/security/HtmlSanitizer.java:30`

**根因**：`Jsoup.clean(html, SAFELIST)` 的 baseUri 为空。Jsoup 校验协议时先把 URL 解析为绝对地址，`/uploads/...` 解析失败 → 属性被丢弃。已用 jsoup 1.18.3 实测：

```
<img src="/uploads/2026/11/x.jpg" alt="a">  →  <img alt="a">        // src 被删
<video src="/uploads/v.mp4">                →  (整段删除)           // 白名单无 video
<a href="/relative/link">l</a>              →  <a>l</a>             // 站内链接也挂
```

**改法**：

```java
private static final String SAFE_BASE_URI = "https://isles.invalid/"; // 仅用于协议判定，不写库

private static final Safelist SAFELIST = Safelist.relaxed()
        .addTags("p","br","h1","h2","h3","h4","s","u","video","source")
        .addAttributes("a","href","title")
        .addAttributes("img","src","alt","width","height")
        .addAttributes("video","src","poster","controls","width","height","preload","muted","loop","playsinline")
        .addAttributes("source","src","type")
        .addProtocols("a","href","http","https","mailto")
        .addProtocols("img","src","http","https")
        .addProtocols("video","src","http","https")
        .addProtocols("video","poster","http","https")
        .addProtocols("source","src","http","https");

static { SAFELIST.preserveRelativeLinks(true); }   // 关键

public static String sanitize(String html) {
    return Jsoup.clean(html, SAFE_BASE_URI, SAFELIST);
}
```

**必须先写** `HtmlSanitizerTest`（目前无任何测试，违反 docs/00 §6.2）：
- 保留 `<img src="/uploads/a.jpg">`
- 保留 `<video src="/uploads/v.mp4" controls>`
- 移除 `javascript:` / `data:` 协议
- 移除 `<script>`、事件属性 `onerror`

## P0-4 裁剪必然降分辨率，且没有"不裁剪"出口

**文件**：`frontend/src/components/media/ImageCropUpload.vue:202-237`

**根因**：`canvas.width = props.outputWidth`（固定 512/960/1280）与源图像素无关；且强制 `aspectRatio`，没有原图出口。4000×3000 照片裁成 512×512；频道背景 4:1 只有 1280×320。另：一律转 JPEG 0.92 → PNG 透明被填白、GIF 动图变静帧。

**改法**：

```ts
const sx = Math.max(0, -offset.value.x / scale)
const sy = Math.max(0, -offset.value.y / scale)
const sw = Math.min(natural.value.width  - sx, props.boxWidth   / scale)
const sh = Math.min(natural.value.height - sy, boxHeight.value  / scale)

const maxW = props.maxOutputWidth ?? 4096          // 仅防超大图，不是常态缩放
const outW = Math.min(Math.round(sw), maxW)
const outH = Math.round((sh / sw) * outW)

canvas.width = outW; canvas.height = outH
ctx.drawImage(image, sx, sy, sw, sh, 0, 0, outW, outH)

const mime = /png|webp/i.test(sourceMime.value) ? 'image/png' : 'image/jpeg'
```

补充要求：
1. `outputWidth` 语义改为 `maxOutputWidth`，三个调用点改值：头像 1024、频道背景 2560、帖子封面 1920（`ChannelProfileForm.vue:117-136`、`ProfileEditDialog.vue:90`、`ChannelAiSettingsPage.vue:279`、`PostComposer.vue:249`）。
2. 新增「使用原图（不裁剪）」按钮：直接上传原始 `File`，完全无损（GIF 动图必须走这条路）。
3. 弹窗底部"导出尺寸"改为显示实际计算值 `outW × outH`。
4. 输出 >10MB 时降质/等比缩小并提示，禁止静默失败。

# 第二轮审查补充（功能与部署）

## P0-6 置顶区失效：置顶老帖后频道页看不到置顶

**证据**：
- `PostMapper.java:24-39` 频道帖子流只有 `ORDER BY id DESC`，**没有 `is_pinned DESC` 优先排序**；
- 后端只有置顶接口（`ContentManageService.java:135`）和 `pinned_at` 字段，**没有任何"取置顶列表"的查询/接口**；
- 前端 `ChannelView.vue:70` 的置顶区来自已加载分页的过滤：`postList.items.value.filter(post => post.isPinned)`。

**后果**：置顶一条 30 天前的帖子 → 第一页 20 条里没有它 → 置顶区整块不显示；翻页时置顶区还会突然出现/消失。FR-CH-05 是 P0。

**改法**：新增 `GET /channels/{id}/posts/pinned`（或列表接口额外返回 `pinned: Post[]`，最多 20 条，按 `pinned_at DESC`），前端置顶区改用该数据源，不再从分页列表过滤。

## P0-7 生产部署自相矛盾：开了 Secure Cookie 却没有 HTTPS

**证据**：
- `deploy/docker-compose.yml` 固定 `COOKIE_SECURE: "true"`；
- `deploy/nginx.conf` 只有 `listen 80`，无 TLS、无 HSTS（`docs/09-部署与运维.md:106` 自己承认"尚未配置 HTTPS 证书"）。

**后果**：按文档用 compose 部署 → 浏览器在 HTTP 下**丢弃 Secure 的 refresh cookie** → access token 15 分钟过期后无法刷新 → 用户被踢下线且登录态无法维持。

**改法（二选一，必须写明）**：① 补 443 + 证书（推荐，同时满足 docs/07 §6 的 HSTS 要求）；② 临时把 `COOKIE_SECURE` 改为 `${COOKIE_SECURE:-false}` 并在 docs/09 标注"HTTP 部署不可用于生产"。

## P1-8 生产可能静默启用开发密钥 / 明文存储 AI Key

**证据**：`docker-compose.yml` 的 `SPRING_PROFILES_ACTIVE: ${SPRING_PROFILES_ACTIVE:-local}` 默认 `local`；`application-local.yml` 为 `app.jwt.secret` 提供开发兜底值（`isles-local-dev-secret-...`），`ApiKeyCipher.java:37-41` 在未配置密钥时**只打一条 warn 就明文存 API Key**。

**后果**：漏配 `JWT_SECRET` 时后端不会像 `JwtService` 那样拒绝启动（被 local profile 兜住），而是用公开的默认密钥签发 token —— 等于任何人可伪造登录态。

**改法**：compose 默认改 `prod`；新增 `application-prod.yml`（不含任何默认 secret）；`ApiKeyCipher` 在 prod profile 下未配置密钥应拒绝启动而不是降级明文。

## P1-9 上传进度未实现（docs/03 §521 明确要求"上传进度"）

`api/media.ts:21` 有 `onProgress` 参数但**全项目零调用**；`timeout: 120000` 固定，200MB 视频要求上行 ≥1.7MB/s，慢网必然超时且无重试。

**改法**：上传组件接 `onProgress` 显示百分比；按文件大小动态设超时（如 `Math.max(120s, size / 0.5MB/s)`）；失败提供重试按钮。

## P1-10 快速评论入口缺"高赞评论预览"（FR-CMT-06）

`PostResponse` 没有 `topComment` 字段，`adapters.ts:220` 的 `topComment` 恒为 null，`PostCard.vue` 也没有渲染它。FR-CMT-06 要求"卡片底部展示点赞高的评论 + 查看全部 N 条评论"。

**改法**：列表接口批量返回每帖 top1 高赞评论（复用 `selectTopLiked` 的 `LIMIT 1`，注意 N+1），卡片底部渲染一行 + "查看全部 N 条评论"。

## P2-11 搜索结果里的帖子卡片无图无封面

`adapters.ts:284-285` 硬编码 `media: []`、`coverUrl: null`，搜索结果的帖子永远没有缩略图。

## P2-12 未加入频道也能在卡片弹窗里写评论

`PostCard.vue:181-186` 打开 `QuickCommentSheet` 时没有传 `:can-comment`，`CommentSection` 默认 `canComment: true`。详情页有校验、弹窗没有 → 非成员写完点发送才被后端 403。

**改法**：`PostCard` 传 `:can-comment="post.channel?.isJoined !== false"`，或让弹窗内先查一次成员状态。

## P2-13 列表里所有视频同时自动播放

`MediaViewer.vue:99-108` 每个 `<video autoplay muted loop>` 无条件自动播放；一屏多视频时耗流量、移动端发烫。建议用 IntersectionObserver，进入视口才播放、离开暂停。

## P2-14 浏览量口径被污染

`PostService.getPostDetail` 每次加载 `+1`，作者本人刷新、F5、爬虫都计入，热度公式（浏览×1）直接被拉高。至少排除作者本人 + 同一会话 30 分钟内去重（Redis/内存）。

## P2-15 帖子编辑不完整

`PATCH /posts/{id}` 支持 `coverUrl`/`media`，但 `PostDetailView.vue:312-322` 的编辑弹窗只有标题 + 正文，封面与媒体无法修改（FR-POST-07"作者可编辑"）。
