# 路线图与里程碑

> 三期交付（已确认）：M1 核心闭环 → M2 管理与运营 → M3 智能与增长。
> 每个里程碑以"可运行、可验收"为准；完成前不启动下一期（可并行准备设计）。

## M1 · 核心闭环（进行中）

### 目标
用户可以注册/登录/游客浏览，创建与加入频道，在频道内发帖、评论、点赞，看到已加入频道的动态，并进行基础搜索。

### 范围
- [ ] 工程骨架：后端 Maven + Spring Boot 4.1、前端 Vue 3 + Vite；本地可构建
- [ ] 数据库：Flyway V1（M1 表结构）、MySQL 本地库
- [ ] 认证：注册、登录、刷新、登出、当前用户；游客只读
- [ ] 用户：资料编辑、用户卡片基础
- [ ] 频道：创建（公开/私密）、详情、加入、我的频道、板块（默认+选择）、邀请链接基础
- [ ] 帖子：快捷发帖、长文发帖、列表（最新/热门/精华）、详情、媒体上传与播放
- [ ] 评论：列表、排序、发表、回复、点赞、快速评论入口
- [ ] 互动：点赞、浏览计数、复制链接分享
- [ ] 动态：已加入频道最新/热门
- [ ] 搜索：关键词、历史、频道/帖子基础结果
- [ ] 通知：互动/系统消息基础列表
- [ ] 前端框架：侧边栏导航、路由、全局布局、加载/空/错误态
- [ ] 测试与文档：单元/集成测试骨架、API 契约、README 启动说明

### 验收
- 全新环境按 README 可启动前后端并完成上述主流程（含测试数据库初始化）。
- 关键路径有自动化测试；CI 可构建。
- 文档与代码同步（API/DB/需求变更）。

## M2 · 管理与运营

### 目标
频道主/管理员可以完整运营频道：成员、身份组、板块、内容管理、数据中心、管理日志；用户有好友与私信。

### 范围
- [ ] 频道设置完整（资料、成员列表/搜索、邀请链接管理、审批、全员禁言、退出/解散）
- [ ] 身份组：默认四组 + 自定义、权限分配、子板块范围
- [ ] 板块：创建/重命名/排序/删除、板块管理员
- [ ] 频道管理中心：首页、资料、内容管理（筛选/批量/置顶/精华）、日志、成员管理
- [ ] 数据中心 v1：概览、趋势、内容/成员分析
- [ ] 举报与处置、系统通知完善
- [ ] 私信（任何人可发起）+ 双向好友 + 实时推送
- [ ] 频道内搜索、结果排序筛选
- [ ] 管理日志（频道内全操作审计）

## M3 · 智能与增长

### 目标
AI 能力上线（频道问问、频道助手问答与自动运营）、热门讨论与频道推荐、搜索联想热词、平台管理后台。

### 范围
- [ ] 频道问问：会话历史、模型选择、深度思考、图片多模态、重新生成、编辑重发、来源引用
- [ ] 频道助手：频道内问答 + 自动总结/发帖/评论/点赞 + 执行日志与开关
- [ ] 热门讨论（全站热门）+ 频道推荐（推荐理由）
- [ ] 搜索联想与热词
- [ ] 数据中心 v2（留存、漏斗、导出）
- [ ] 平台管理后台：AI 配置（LMStudio/OpenAI 兼容）、内容治理、平台数据
- [ ] 桌面端可行性验证

## 依赖与风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 本机 MySQL 账号未就绪 | 阻塞后端联调 | 尽快获取凭据或建专用账号（见 README 环境说明） |
| 本机无 Docker/Redis | 部署与限流验证延后 | M1 用 DB 存令牌；Redis 在 M2 前补齐 |
| LMStudio 本地模型性能/视觉能力 | AI 体验 | M3 前实测模型；不支持时降级 |
| 单人维护 + AI 协作 | 质量与进度 | 规范 + 测试 + 评审门禁，小步提交 |
| 需求范围大 | 延期 | 严格按里程碑验收，范围变更走需求变更记录 |
