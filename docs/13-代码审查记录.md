## 0. 结论摘要

| 维度 | 结论 |
| --- | --- |
| 数据一致性 | ✅ 干净。47 表 / 146 索引 / 90 外键 / 47 实体字段 / 103 处 mapper 列引用，与实际库 **0 差异** |
| 权限架构 | ✅ 有统一入口。平台侧 `@RequirePlatformPermission`（53 端点覆盖 52），频道侧 `ChannelAccessService.require*Permission`（28 个服务注入、27 处调用） |
| 原疑点澄清 | `ChannelAssistant` / `Invite` 不注入 accessService **不是漏洞**（前者走 `ChannelAiSettingsService` 的权限校验，后者靠 token + `requireActiveChannel`）；`GET /admin/me` 本就不该有权限注解 |
| 主要风险 | ① 合规控制 fail-open；② 配额/闸门 count-then-act；③ 前端请求竞态与状态不刷新；④ 测试负向用例只验状态码 |
